# 成熟国赛论文训练边界

本目录只沉淀可迁移的建模工作流，不复制成熟论文的正文、图表或无许可代码。训练材料用于回答“为什么这样建模、怎样证伪、怎样报告不确定性”，不能替代本届赛题的独立推导与真实执行。

本轮围绕 A 题提炼三类能力：

1. 先用可核验的几何与图算法完成确定性子问题，再引入随机模拟；
2. 随机实验固定种子、报告置信区间，并用样本量收敛与独立复算约束结论；
3. 优化结论只在明确网格、置信水平和搜索精度内成立，不能把启发式可行解称为全局最优。

来源、版本、许可与使用方式见 `source_manifest.json`，独立方法笔记见 `method_cards.md`。

## 论文级参考目录

`cumcm_high_score_papers_catalog.json` 与同名 CSV 当前登记 472 篇去重后的 CUMCM 单篇论文参考，覆盖 1992—2025 年中的 32 个年份。目录来自固定 GitHub commit，已排除赛题、规则、附件、合集、评述和重复 blob；详细清洗与分级见 `cumcm_high_score_papers_catalog.md`。

这 472 篇不是“472 篇已官方核验国一”：18 篇已按年份和展示编号匹配教育部中国大学生在线的官方论文展示，另 454 篇为成熟整理库标注的优秀论文候选。所有记录均为链接和元数据，不在本仓库镜像第三方论文全文。
