# 2026 第三次模拟题 A：煤矿巷道支护

本目录记录 A 题“煤矿巷道支护问题”的独立建模工作。完整可复现仓库在本次 ChatGPT 任务产物 `coal-roadway-support-2026` 中；本分支用于保留关键方案、结果与后续迭代入口。

## 核心结果

- 标准扭矩系数：d=18/20/22 mm 时 K=0.1620/0.1831/0.1899。
- 现场统计临界力矩：岩石 125 N·m、煤体 175 N·m；岩石测点不确定性较高，保守施工阈值建议约 200 N·m。
- 工况 A：Tmax=612.0 N·m，锚杆屈服控制，钢带非必须。
- 工况 B：Tmax=487.4 N·m，围岩压陷控制，钢带必须；最低等效扩散宽度约 211.3 mm。
- 偏心：参考 κ=1.20 时 e=0/5 mm 的综合允许力矩约 337.5/101.5 N·m。
- 普氏系数参考分区：f<2.27 时 Topt≈133.92f N·m；f≥2.27 时 Topt≈303.79 N·m。

## 建模路线

1. 对 T=KPd 做过原点 OLS，并用 Huber 回归检查稳健性。
2. 对现场数据构造 Kij=T/(dPij)，用后缀稳定化判据识别临界力矩，并做 5000 次测点 Bootstrap。
3. 把锚杆屈服、粘结破坏、围岩压陷统一转换为轴力上限并取最小值，判断钢带需求。
4. 用偏心轴力 + 扭转的 Von Mises 强度准则，引入应力集中系数 κ 与偏心托盘接触压力修正。
5. 对普氏系数分区显式引入模量比 Rm=E/σc，避免虚构 E(f) 的确定关系，并用 Monte Carlo 做参数扰动。
