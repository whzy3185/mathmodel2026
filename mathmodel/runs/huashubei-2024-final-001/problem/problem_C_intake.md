# C 题审题：“老外游中国”

- Q1 可由官方 CSV 直接完成；最高评分为 5.0，详细城市排名须在主实验选 C 时再形成正式结果。
- Q2 需要城市规模、环境、人文、交通、气候、美食等外部指标，并处理指标年份、尺度与缺失。
- Q3–Q5 需要可追溯的高铁时刻、行程时间、票价、机场和门票解析；路线是带 144 小时资源约束的奖励收集路径问题。
- 实测 352 个文件仅 33174 条记录，不是题面所称 35200 条；只有 20499 条评分非空，且有 2632 条同城名称/网址重复成员。

由于外部数据依赖高且原始数据需大规模清洗，本轮不选 C。若 A 题发生不可修复的 D-H 解释冲突，仍优先切换到数据更完整的 B，而不是直接切换 C。
