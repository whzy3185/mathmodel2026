# 科研绘图仓库与 Skill 候选清单（第二轮）

> 调研快照：2026-08-14
>
> 目标：继续寻找能让 Agent 直接产出论文级数据图、三维图、方法图和可编辑图稿的仓库与 Skill，并区分“宣传热度”“可运行代码”“论文实验”“独立社区验证”。
>
> 适用项目：华数杯 A/B/C 题论文图表重做与后续 Figure Agent Harness 建设。

## 1. 结论先行

本轮没有发现任何一个仓库或 Skill 能被可靠地描述为“输入论文或数据后，零人工复核即可稳定得到 camera-ready 图”。真正可用的路线是组合式工作流：

1. **数据证据图**使用 Python/R 可执行代码，并把数值、文本、视觉三类检查拆开；优先考察 SciPilot、K-Dense、ggplotAgent、MatPlotAgent 和 PlotGen 的机制。
2. **方法图与流程图**优先交付原生 SVG、PPTX 或 draw.io，而不是最终只给 PNG；优先考察 AutoFigure、Scientific Illustrator、LiveFigure、Crafter/CraftEditor。
3. **专业三维与体数据图**可考察 SciVisAgentSkills；它是本轮少数真正做了“同一 Agent 有/无 Skill”对照实验的项目，但应用范围不是普通统计图。
4. **图像生成模型**适合探索构图和产生候选，不应直接绘制曲线、坐标、数值、误差条或最终文字。
5. stars、安装量、安全扫描和作者展示图只能证明传播或安装链路，不能证明科学正确性。没有独立 benchmark、盲评或真实用户复现的候选，必须先做攻击测试。

## 2. 证据分级

本清单采用下面的分级，而不是按星标排序：

| 等级 | 含义 |
|---|---|
| A | 有公开代码、可执行评测、消融或有/无 Agent/Skill 对照，并有人类评测或较可信独立复现 |
| B | 有公开代码和测试，有论文自报 benchmark 或明确工程 QA，但独立复现不足 |
| C | 代码或 Skill 基本完整，有少量样例/用户反馈，无严格 benchmark |
| D | 主要是提示词、展示页、聚合站评分或作者自述，无法验证科学正确性 |

额外门禁：

- **无许可证**：即便技术上可用，也不能直接复制进项目或安装为生产依赖。
- **SVG 内嵌 PNG**：只能称“部分可编辑”，不能称“全矢量”。
- **只看最终 PNG 的 VLM judge**：不能核验数据来源、公式、边关系和数值一致性。
- **只在大图预览中好看**：必须在论文实际版心、最终缩放和 PDF 字体嵌入后再验收。

## 3. 科研图 Agent 仓库审计

### 3.1 AutoFigure

- 仓库：[ResearAI/AutoFigure](https://github.com/ResearAI/AutoFigure)
- 论文：[AutoFigure](https://arxiv.org/abs/2602.03828)
- 快照：约 1,819 stars、136 forks，MIT。
- 输出：原生 SVG 或 mxGraph XML；可从长文本/PDF规划结构，并生成多个增强候选。
- 工程：公开 SDK、前后端、PDF 提取、Playwright 渲染和 critic/refinement 流程。
- 证据：FigureBench 包含 3,300 个文本—图形样本；10 位论文一作对自己的 21 篇论文做评估，66.7% 表示愿用于 camera-ready，AI 方法间胜率 83.3%。
- 风险：论文类盲测胜率仅约 53%；小字体、密集背景和字符级拼写仍会失败；人评样本小；critic 与生成器可能共享盲区。

**评级：A-/B+。** 适合吸收“Reasoned Rendering、结构规划、多个候选、原生 SVG/XML”的机制，但 66.7% 本身已说明不能免审。

### 3.2 AutoFigure-Edit

- 仓库：[ResearAI/AutoFigure-Edit](https://github.com/ResearAI/AutoFigure-Edit)
- 论文：[AutoFigure-Edit](https://arxiv.org/abs/2603.06674)
- 快照：约 4,105 stars、266 forks，MIT。
- 输出：先生成 raster，再用 SAM3、RMBG 与模板转换成可编辑 SVG，并提供网页编辑器。
- 证据：217 名用户、262 份真实使用反馈；语义、完整性、视觉的平均分约 4.04、4.11、3.95/5；48% 认为不需要重大修改即可用于论文；SVG 转换正确性均值 3.60/5。
- 风险：复杂图标经常仍是嵌入 SVG 的 PNG；分割错误会传播；1K/2K 输入易模糊，仓库推荐 4K；48% 远不是稳定直出。

**评级：A-/B+。** 可作为“位图候选到结构化编辑稿”的转换器，但不能把可编辑性等同于语义正确性。

### 3.3 Crafter / CraftEditor

- 仓库：[HaozheZhao/Crafter](https://github.com/HaozheZhao/Crafter)
- 论文：[Crafter](https://arxiv.org/abs/2605.30611)
- 快照：约 153 stars、11 forks，MIT。
- 机制：多样化计划探索、结构化 corrective layer、directive critic、verify-then-refine；CraftEditor 把位图转换为可编辑 SVG。
- 证据：CraftBench 279 例；消融中只保留单候选 `K=1` 下降 8.56 分，移除结构化改正下降 8.90 分；CraftEditor 在 80 图上 8.04/10，AutoFigure-Edit 为 6.91；三位人工标注者与自动裁判一致率 72%，κ=0.58。
- 风险：仍高度依赖专有图像模型和 VLM judge；最多四个候选、三轮修订，成本和时延较高；κ=0.58 表明自动裁判不能独立放行。

**评级：B+。** 本项目应直接吸收“先并行探索结构差异，再做局部修正”的设计，而不是反复修同一张错误草图。

### 3.4 LiveFigure

- 仓库：[tsinghua-fib-lab/LiveFigure](https://github.com/tsinghua-fib-lab/LiveFigure)
- 论文：[LiveFigure](https://arxiv.org/abs/2605.23527)
- 快照：约 14 stars、0 forks，未发现许可证。
- 输出：PPTX、Python 和 PNG；流程为参考检索、生成可执行脚本、视觉诊断、定点改代码。
- 证据：论文报告 80% 的结果在 17 次人工原子编辑以内达到 publication readiness，NanoBanana 为 24%；对 NanoBanana 人类偏好胜率约 60%。
- 风险：结论不是“零人工”；所谓全矢量 PPTX 仍可能包含 `icon_*.png`；外部 API、LibreOffice、参考向量索引等依赖较重；无许可证阻止直接复用。

**评级：B。** “可执行脚本 + PPTX 原生对象 + 定点修正”很值得借鉴，但当前只作研究参考。

### 3.5 Scientific Illustrator

- 仓库：[icebird1998/scientific-illustrator](https://github.com/icebird1998/scientific-illustrator)
- 许可：MIT。
- 输出：PowerPoint/WPS/draw.io 的原生可编辑对象。
- 机制：Designer—Drawer—Reviewer—Corrector；通过 COM、Office.js、OOXML 或 draw.io API 做区域级修订。
- 优点：最终交付不是扁平位图；局部修改不会强迫整图重新生成；更贴近论文团队真实返工方式。
- 风险：当前证据主要来自作者展示；运行环境复杂；尚未找到严格的独立盲评或跨领域 benchmark。

**评级：B-/C+。** 由于数学建模论文经常需要改中文标签、箭头和公式，优先级高于纯位图生成 Skill，应进入攻击测试。

### 3.6 PaperVizAgent（官方 PaperBanana 实现）

- 仓库：[google-research/papervizagent](https://github.com/google-research/papervizagent)
- 论文：[PaperBanana](https://arxiv.org/abs/2601.23265)
- 快照：约 477 stars、86 forks，Apache-2.0。
- 机制：Retriever—Planner—Stylist—Visualizer—Critic；支持并行多个候选和 2K/4K 放大。
- 证据：论文在 50 例、3 位人评中报告相对 vanilla 模型的胜/平/负为 72.7%/20.7%/6.6%。
- 风险：主要最终产物仍为 PNG；仓库明确为 demonstration、非 production；检索数据和 benchmark 尚未完整随仓库公开；对统计图仍有数值幻觉风险。

**评级：B。** 可作构图和风格候选生成器，不能绘制数据证据图，也不能跳过文字、箭头、连接关系和公式复核。

### 3.7 ggplotAgent、MatPlotAgent 与 PlotGen

| 项目 | 仓库/论文 | 主要证据 | 限制 | 评级 |
|---|---|---|---|---|
| ggplotAgent | [仓库](https://github.com/charlin90/ggplotAgent) | CSV→R/ggplot2→执行调试→视觉检查；20 任务中可执行率 100% 对 85%，Publication-Ready 1.9 对 0.7 | 作者自建 benchmark 仅 20 例，社区采用几乎为空 | B- |
| MatPlotAgent | [仓库](https://github.com/thunlp/MatPlotAgent) / [论文](https://arxiv.org/abs/2402.11453) | MatPlotBench 100 例；GPT-4 48.86→61.16，移除视觉反馈后 53.44 | 项目较旧、未发现许可证、不能证明真实研究数据一致性 | B |
| PlotGen | [论文](https://arxiv.org/abs/2502.00988) | 把数值 critic、文本 critic、视觉 critic 分开；论文称比 MatPlotAgent 高约 4–6% | 无官方公开实现，只能复刻思想 | B（机制）/不可安装 |

**本项目取舍：** 数据图不采用任何纯图像生成路线；把 PlotGen 的三 critic 结构叠加到 K-Dense/SciPilot 的数据真实性、导出和样式规则上。

### 3.8 SciVisAgentSkills

- 仓库：[KuangshiAi/SciVisAgentSkills](https://github.com/KuangshiAi/SciVisAgentSkills)
- 论文：[SciVisAgentBench](https://arxiv.org/abs/2606.05525)
- 快照：约 12 stars、1 fork；未发现许可证。
- 实际内容：ParaView、napari、VMD/MDAnalysis、TTK 四套 Skill，均有 `SKILL.md`，部分包含参考文件与资产。
- 证据：108 个专家设计多步任务，五个任务套件，对 Codex 和 Claude Code 做三次重复的有/无 Skill 对照。Codex 加 Skill 后：ParaView 60.17→66.67、分子可视化 62.30→73.13、生物图像 41.90→55.00、拓扑 76.43→83.73。
- 风险：部分完成率反而下降；token 消耗随模型和 harness 变化；它解决的是专业体数据、分子和拓扑软件，不是常规 Matplotlib 或方法框图；无许可证不能直接复制。

**评级：A（对特定工具链的 Skill 效果）/不适合作为通用绘图 Skill。** 它最重要的意义是证明“精心编写且工具特定的 Skill 可能有效”，不是证明通用论文作图已解决。

## 4. 可安装 Skill 审计

### 4.1 K-Dense `scientific-visualization`

- 仓库：[K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)
- Skill：[scientific-visualization](https://github.com/K-Dense-AI/scientific-agent-skills/tree/main/skills/scientific-visualization)
- 快照：skills.sh 约 1.2k 次安装；整个 Skill 集约 33.5k stars、3.3k forks，MIT。安装量属于单项传播信号，stars/forks 属于整个仓库，二者都不是质量 benchmark。
- 已核查的真实文件：`SKILL.md`、`nature.mplstyle`、`publication.mplstyle`、publisher profiles、palettes，以及 metadata、palette、export、style preview 脚本和合成数据测试。
- 可靠之处：明确禁止隐藏、捏造或选择性增强数据；记录来源、缺失、单位、不确定性和变换；固定物理尺寸；检查 PDF/SVG 元数据、字体、调色板、发布商导出计划；脚本包含覆盖保护、符号链接拒绝和原子输出。
- 尚缺证据：没有该单项 Skill 的独立盲评、专门安装量或论文 benchmark。
- 安全与结构：skills.sh 显示三项安全检查通过；仓库 CI 要求带脚本的 Skill 配有测试，并检查链接、脚本解析和 `--help` 结构。安全通过不能替代输出质量验证；仓库还提示各 Skill 可能有独立许可元数据，安装前仍需逐项复核。

**决定：进入本地受控测试，但不能仅凭仓库总 stars 认定为成熟。**

### 4.2 `scipilot-figure-skill`

- 仓库：[Haojae/scipilot-figure-skill](https://github.com/Haojae/scipilot-figure-skill)
- 快照：约 1.8k stars、66 forks，MIT。
- 能力：数据剖析、图型选择、期刊尺寸、CJK 字体、Matplotlib/Seaborn/SciencePlots、程序化视觉 QA、灰度预览和矢量导出。
- 适配优势：会拦截小样本均值柱状图、双 Y 轴、3D 柱状图、彩虹色图和缺失不确定性说明等常见论文问题，适合中文数学建模。
- 风险：只有少量提交，无独立 benchmark 或人类盲评；高 stars 与短维护史需要通过本项目数据实测确认。

**决定：进入本地受控测试。**

### 4.3 neuromechanist `figures` plugin

- 仓库：[neuromechanist/research-skills](https://github.com/neuromechanist/research-skills)
- 旧版 Skill 页面：[scientific-figures](https://www.skills.sh/neuromechanist/research-skills/scientific-figures)
- 快照：仓库约 42 stars、7 forks，BSD-3-Clause；旧页面仅约 4 次安装。
- 当前仓库比聚合页完整：包含 `ai-full-figure`、`figure-qa`、`plot-styling`、`scientific-figure`、`svg-figure`、`svg-primitives`、`transparent-icons`。
- 工程证据：精确毫米尺寸 SVG、文本保留、有效字体大小检查、Inkscape/cairosvg 导出、SVG/PDF/raster QA 脚本、独立新上下文评审和端到端测试。
- 风险：社区采用极低；“期刊会接受”类表述过强；期刊规范快照可能过时；没有独立质量 benchmark。

**决定：适合拆取 QA 机制，不以社区验证成熟度背书。**

### 4.4 `engineering-figure-agent`

- 仓库：[heyu-233/engineering-figure-agent](https://github.com/heyu-233/engineering-figure-agent)
- 快照：约 291 stars、15 forks，MIT。
- 关键优点：明确把方法示意图放入 image mode，把柱状图、热图、散点图等放入 plot mode，并要求本地代码使用真实数值；对中文和 Windows 更友好。
- 工程：包含 publication plot 脚本、build spec、检查器、JSON schemas、CLI/plot/prompt/provider safety 测试。
- 风险：未找到独立用户 benchmark；当前证据主要为作者文档和自测。

**决定：进入攻击测试，尤其适合本项目 A/B/C 题的混合图型。**

### 4.5 `nature-figure`

- Skill 页面：[nature-figure](https://www.skills.sh/yuan1z0825/nature-skills/nature-figure)
- 所属仓库：[Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills)
- 快照：平台约 9.4k 安装；整个 Skill 集约 35.2k stars、2.0k forks，Apache-2.0。
- 正面：安装链路成熟；有 Python/R 分流、数据图与 schematic 分流、参考和 QA。
- 独立负面：中文社区用户报告复杂图不可用、结果与展示差距大、工程领域适配不佳、局部修图造成整图错位等问题。
- 解释：安全扫描只说明依赖和恶意行为风险，安装量说明传播，不说明数据、公式、语义或最终审美正确。

**决定：仅作规范路由与候选参考，不把它视为“已被很多人验证的投稿级结果生成器”。**

## 5. 中文社区、Reddit 与聚合站证据

### 5.1 可采信的负面反馈

- [PaperBanana 的独立生物学用户讨论](https://www.reddit.com/r/biology/comments/1syv9ik/pi_recently_had_me_evaluate_several_ai_figure/)报告逻辑不连贯和科研语义问题。
- [AutoFigure-Edit 中文社区实测一](https://linux.do/t/topic/1568185)指出图标并非 SVG、部分元素可编辑但识别效果一般。
- [AutoFigure-Edit 中文社区实测二](https://linux.do/t/topic/2015738)认为其某些输出质量低于 PaperBanana。
- [AutoFigure-Edit 团队讨论](https://linux.do/t/topic/2003131)明确承认 100% 复现不可实现。
- [Nature Skill 负面讨论一](https://linux.do/t/topic/2456658)和[负面讨论二](https://linux.do/t/topic/2176729)显示复杂图、工程适配与成图质量存在明显不稳定性。
- [局部 TikZ/AI 修图导致整图移位](https://linux.do/t/topic/1936803)说明重新生成整图不是可靠的局部编辑机制。
- [完整图→拆分→人工修订的实践](https://linux.do/t/topic/1917914)与[逻辑图使用 PlantUML/Mermaid/Python/Matlab 的建议](https://linux.do/t/topic/1886836)共同支持“结构化源文件 + 人工最后一公里”。

这些反馈不能替代受控 benchmark，但足以推翻“一键稳定直出”的强宣传。

### 5.2 传统工具的采用信号更强

Illustrator、MATLAB/FigureBest 等传统科研绘图教程在中文社区拥有数十万播放量，例如 [Illustrator 科研绘图教程](https://www.bilibili.com/video/BV1W8411h7Af/)、[另一套 Illustrator 教程](https://www.bilibili.com/video/BV1SR4y157uk/)和 [FigureBest MATLAB 教程](https://www.bilibili.com/video/BV1RU4y1y7Ff/)。这不是质量 benchmark，但说明“原生可编辑对象 + 人工精修”拥有远强于新生 Agent Skill 的实际采用基础。

### 5.3 不采信的伪社会证明

- 某些聚合站的 4.8/5、数十条评论出现大量完全相同的模板文本，无法确认是真实用户。
- 只显示“4.5（120）”而没有可追溯评论、任务、失败案例和版本号的评分，不作为证据。
- skills.sh 安装数可作为传播信号，不能转换为投稿成功率或科学正确率。
- 仓库总 stars 不能分摊给其中某一个 Skill。

## 6. 对 A/B/C 题的具体映射

| 论文任务 | 首选路线 | 候选工具/机制 | 关键验收 |
|---|---|---|---|
| A 题六自由度机械臂零位图 | 几何代码/矢量原生对象 | Python 3D + Scientific Illustrator/PPTX 做说明层 | 关节轴、坐标系、零角定义与 DH 参数一致 |
| A 题三维轨迹与障碍物 | Python 真实坐标生成，多视角候选 | K-Dense/SciPilot 规范；必要时专业 3D 工具 | 轨迹点、障碍物、碰撞间隙逐点可复算 |
| A 题优化收敛、误差、能耗 | 代码型数据图 | PlotGen 三 critic + K-Dense export QA | 原始数值、单位、不确定性、对数轴逐项核验 |
| B 题布局与连线 | 真实单元和 pin 坐标绘制 | Python/SVG；禁用文生图 | HPWL/RSMT 与绘制线段一一对应 |
| B 题密度/拥塞热图 | 代码型矩阵图 | SciPilot/K-Dense | 色标范围、网格尺寸和溢出值明确 |

## 7. 下一轮攻击测试队列

### 7.1 数据图组

第一批测试三个候选：

1. K-Dense `scientific-visualization`；
2. `scipilot-figure-skill`；
3. `engineering-figure-agent` 的 plot mode。

统一输入同一份项目真实结果数据，要求各自产出 3 个结构不同的候选。评分不只看美观，而看：

- 数据点/矩阵逐值一致率；
- 单位、误差定义、样本量和变换是否完整；
- 实际论文宽度下最小字号；
- 灰度和色觉缺陷可辨识性；
- SVG/PDF 字体与元数据；
- 脚本能否一键重跑；
- 是否保存选择与拒绝理由。

### 7.2 方法图组

第一批测试三个候选：

1. AutoFigure 原生 SVG/XML；
2. Scientific Illustrator 的 PPTX/draw.io 原生对象；
3. Crafter/CraftEditor 的多候选与 SVG 转换。

统一输入同一段 A/B/C 题方法正文和强制语义图，评测：

- 节点、边、方向、公式、术语精确率；
- 漏项、臆造项和错误连线数量；
- SVG/PPTX 中独立可编辑对象比例；
- 是否存在内嵌 raster；
- 局部修订是否影响无关区域；
- 在真实 DOCX/PDF 版心下是否仍可读。

### 7.3 放行门槛

任何候选只有同时满足下列条件才可进论文正文：

1. 数据/语义硬检查全部通过；
2. 没有未说明的位图伪矢量；
3. 独立 Agent 在新上下文完成攻击性 QA；
4. 人工复核高风险公式、箭头和数值；
5. 最终 DOCX 与 PDF 实际版面复检通过；
6. 保存源码、资产、参数、依赖、候选、评分和拒绝记录。

## 8. 最终决定

本轮建议**不继续盲目安装更多 prompt-only Skill**。先围绕以下四个方向做真实题数据攻击测试：

- 数据图规范与 QA：K-Dense + SciPilot；
- 混合图型与 Windows 工作流：engineering-figure-agent；
- 可编辑方法图：AutoFigure + Scientific Illustrator；
- 多候选与结构化纠错机制：Crafter。

SciVisAgentSkills 保留为“Skill 有效性研究证据”和未来专业三维可视化备选；LiveFigure、neuromechanist figures plugin、ggplotAgent 作为对照；PaperBanana 只承担构图探索。所有最终论文证据图仍必须由真实数据或结构化源文件生成，并经过独立核验。
